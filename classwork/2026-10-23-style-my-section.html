My work

I styled my section with a green palette and one shared stylesheet.

My color palette

  • Background: #D2E58E — light green
  • Text: #273014 — dark olive
  • Headings: #3E4916 — deep green
  • Borders and accents: #8C9E49 — olive green
  • Links: #29450F — forest green
  • Cards and navigation: #F5F8E9 — pale cream green

My font

I chose Arial for its simple, readable letters. My font stack is Arial, Helvetica, sans-serif, so another sans-serif font can be used if Arial is unavailable.

Why use one stylesheet?

One stylesheet keeps all my pages consistent. I can change a color or font once in style.css, and every linked page updates. This saves time and avoids copying the same CSS into each page.

Selectors and bonus features

I used element selectors such as body, h1, and a, plus class selectors such as .logo, .categories, and .entries that are used in my HTML. My palette is stored as CSS variables in :root, and links change on hover and keyboard focus.
