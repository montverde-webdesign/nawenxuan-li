My work

My colors

  • Page background: #d2e58e
  • Text: #273014
  • Headings: #3e4916
  • Links: #29450f
  • Accent: #8c9e49

My font

My font is Arial, Helvetica, sans-serif. I used it on the whole page (it's in my body rule).

Rules I wrote

Rule 1

body {
  margin: 0;
  background-color: var(--background);
  color: var(--text);
  font-family: Arial, Helvetica, sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

It sets the default colors, font, and spacing for my entire webpage.

Rule 2

h1 {
  padding: 16px;
  border: 5px solid var(--accent);
  border-bottom-color: var(--heading);
  font-size: 2rem;
  overflow-wrap: anywhere;
}

It makes my main heading large (32px) and puts a thick olive-green border box around it.

Rule 3

nav {
  max-width: 960px;
  margin: 0 auto;
  padding: 20px;
}

It centers my navigation bar on the page, caps its width at 960px, and adds 20px of inner breathing room.

My class

.logo {
  font-size: 1.25rem;
  font-weight: bold;
}

I used it at the very top of my page (in the navigation bar/header), right above my menu links.. It makes my site's title slightly larger (20px) and bold so it stands out from my regular navigation links.

What I'd change now

I would add text-decoration: none; and color: var(--heading); inside .logo to remove the link underline and match my site's dark heading color.
